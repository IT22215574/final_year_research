### ⛽ **Step 3: Fuel Price Features**
```
Backend/dataset/processed/fuel_price_daily.csv
├── Rows: 2000+
├── Columns:
│   ├── date: Calendar date
│   ├── lk_price: Current day kerosene price
│   ├── lk_price_lag1: Yesterday's price (lag-1)

├── Time Range: From first fuel price to today
├── Generated by: process_fuel_price.py
└── Update Frequency: On price changes
```

```
Backend/dataset/processed/merged_festival_features.csv

### 🔗 **Step 6: Complete Merged Dataset**
```
Backend/dataset/processed/final_merged_dataset.csv
├── Rows: 5000+
├── Combines:
│   ├── Fish prices (date, fish_id, price)
│   ├── Fuel prices (lk_price, lk_price_lag1, lk_price_lag2, lk_price_change)
│   ├── Weather (temp_c_mean, humidity_mean, wind_speed_max, rainfall_sum, bad_weather_any)
│   └── Festivals (festival_name, is_festival)
├── Generated by: merge_all_data.py
└── Purpose: Single source of truth for training
```

### 🧠 **Step 7: Engineered Features (For ML Model)**
```
Backend/dataset/processed/features_dataset.csv
├── Rows: 1000+
├── 30+ ML Features:
│
│  🕐 Time Features:
│  ├── day_of_week, month, year, week_of_year, is_weekend
│  ├── month_sin, month_cos (cyclical encoding)
│
│  🌊 Fishing Seasons (Sri Lankan):
│  ├── is_waragam_west (SW monsoon: May-Sept, rough)
│  ├── is_waragam_east (NE monsoon: Oct-Jan, rough)
│  ├── is_awaragam (Feb-Apr, calm/open)
│  └── fishing_season (0=Awaragam, 1=Waragam-West, 2=Waragam-East)
│
│  ⛽ Fuel Impact:
│  ├── lk_price, lk_price_lag1, lk_price_lag2
│  ├── lk_price_change, lk_price_pct_change
│  └── lk_price_rose (binary: did price go up?)
│
│  🌡️ Weather Effects:
│  ├── temp_c_mean, humidity_mean, wind_speed_max, rainfall_sum
│  ├── bad_weather_any (binary: rain>5mm OR wind>30 km/h?)
│  └── weather_effect (binary: rain > 10mm?)
│
│  🎉 Festival/Holiday Impact:
│  ├── is_festival_day, is_poya, is_holiday
│  ├── days_to_festival, before_festival_window
│  ├── poya_effect, festival_effect
│
│  🎯 Composite Signal:
│  └── price_behavior_signal (sum of weather + poya + festival effects)
│
├── Generated by: feature_engineering.py
└── Used for: RandomForest + XGBoost training
```

### 🔮 **Step 8: Future Features (14-day forecast)**

Backend/dataset/processed/future_features.csv

### 📈 **Step 9: Price Predictions (Output)**
```
Backend/dataset/processed/future_price_predictions.csv

├── Columns:
│   ├── date: Prediction date

## 🔍 **How to Access Datasets**

### In Python:
```python
from pathlib import Path

# Access processed datasets
backend = Path("Backend")
features_data = backend / "dataset" / "processed" / "features_dataset.csv"

import pandas as pd
df = pd.read_csv(features_data)
print(f"Loaded {len(df)} records with {len(df.columns)} features")
```

### In FishPricePredictor:
```python
from model.fish_price_prediction.predict.price_predictor import FishPricePredictor

predictor = FishPricePredictor()
# Automatically loads:
# - Models from models/
# - Fish database from data/fish_names.csv
# - Features_dataset for analysis

prediction = predictor.predict("2026-05-10")
print(f"Predicted price: LKR {prediction['price']:.2f}")
```
